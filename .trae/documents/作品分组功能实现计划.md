# 作品分组功能实现计划

## Context（背景）

当前作品广场只有一个平铺的作品列表，随着作品数量增加，用户需要按分组浏览和管理作品。本次需求：
- 支持自定义分组，默认有"默认"分组
- "全部作品"是虚拟筛选，不是真实分组
- 新作品不选分组时归入"默认"分组
- 每个作品只能属于一个分组
- 管理后台可独立管理分组（新增/删除）
- 作品广场使用侧边栏分组列表筛选作品

## 数据结构设计

### 新增文件：`data/groups.json`
```json
["默认"]
```
有序的分组名称列表，初始只有"默认"。

### 修改 `data/works.json` 中每个 work 对象
新增 `group` 字段：
```json
{
  "id": "a19ece02",
  "title": "毛豆上货",
  "group": "默认",
  ...
}
```
现有作品通过迁移脚本自动补上 `"group": "默认"`。

## 实现步骤

### 1. 后端 `app.py` 改动

**新增数据层（参照现有 `load_avatars`/`save_avatars` 模式）：**
- 新增常量 `GROUPS_FILE = os.path.join(BASE_DIR, "data", "groups.json")`
- 新增 `load_groups()` 函数：读取 groups.json，若不存在则返回 `["默认"]`
- 新增 `save_groups(groups)` 函数：写入 groups.json
- 新增 `ensure_work_group(work)` 辅助函数：确保 work 有 group 字段，没有则设为"默认"

**新增分组管理路由 `/admin/groups`（POST，admin_required）：**
- 操作类型 `action`：`add` / `delete`
- `add`：接收 `name` 参数，去重后追加到 groups 列表
- `delete`：接收 `name` 参数，从 groups 列表移除；同时遍历 works.json，将该分组下所有作品的 group 改为"默认"
- 不允许删除"默认"分组

**修改 `works_list` 路由：**
- 读取 query 参数 `group`（可选）
- 加载所有 works，对每个 work 调用 `ensure_work_group`
- 若指定了 group 参数，过滤出该分组的作品
- 传递 `groups` 列表和当前 `current_group` 给模板

**修改 `upload` 路由（POST 处理）：**
- 接收 `group` 表单字段，默认"默认"
- 若该分组不存在于 groups 列表中，自动添加
- 保存到 work 对象的 `group` 字段

**修改 `edit_work` 路由（POST 处理）：**
- 接收 `group` 表单字段
- 若该分组不存在于 groups 列表中，自动添加
- 更新 work 对象的 `group` 字段

**修改 `upload` / `edit_work` 路由（GET 处理）：**
- 传递 `groups` 列表给模板，用于渲染下拉选择框

### 2. 模板改动

**`templates/works.html` — 侧边栏分组列表：**
- 改为左右两栏布局：左侧 sidebar（分组列表），右侧作品网格
- 侧边栏顶部固定"全部作品"标签，下方列出所有分组
- 当前选中分组高亮显示（渐变背景）
- 点击分组链接跳转 `/works?group=分组名`
- 每个分组名后显示该分组下作品数量
- 响应式：移动端侧边栏变为顶部横向滚动的标签条

**`templates/admin.html` — 分组管理 + 表格分组列：**
- 在标题区下方新增"分组管理"卡片：
  - 输入框 + "添加分组"按钮（表单 POST 到 `/admin/groups`，action=add）
  - 已有分组标签列表，每个标签有删除按钮（POST 到 `/admin/groups`，action=delete，带 confirm）
  - "默认"分组不可删除（不显示删除按钮）
- 表格新增"分组"列（在"备注"列之后），显示分组标签

**`templates/upload.html` — 分组下拉选择：**
- 在"备注"字段下方新增"作品分组"表单项
- `<select>` 下拉框，选项来自 `groups` 列表
- 默认选中"默认"

**`templates/edit.html` — 分组下拉选择：**
- 在"备注"字段下方新增"作品分组"表单项
- `<select>` 下拉框，选项来自 `groups` 列表
- 默认选中当前作品所属分组 `work.group`

### 3. 数据迁移

在 `app.py` 的 `load_works()` 函数中增加兼容逻辑：
- 读取 works 后，遍历每个 work，若没有 `group` 字段则自动补上 `"默认"`
- 这样无需手动迁移现有数据，首次加载自动完成

## 关键文件清单

| 文件 | 改动类型 |
|------|---------|
| `app.py` | 新增分组数据层、分组管理路由，修改 upload/edit/works_list 路由 |
| `data/groups.json` | 新建，初始内容 `["默认"]` |
| `templates/works.html` | 改为侧边栏布局，添加分组筛选 |
| `templates/admin.html` | 添加分组管理卡片，表格增加分组列 |
| `templates/upload.html` | 添加分组下拉选择框 |
| `templates/edit.html` | 添加分组下拉选择框 |

## 复用的现有模式

- `load_avatars()` / `save_avatars()` 模式 → 复制为 `load_groups()` / `save_groups()`
- `admin_required` 装饰器 → 用于分组管理路由
- `flash()` 消息提示 → 分组操作反馈
- CSS 类 `.remark-tag` → 分组标签样式可复用

## 验证方式

1. 启动本地服务 `python app.py`
2. 访问 `http://127.0.0.1:5000/works`，确认左侧出现分组侧边栏，"全部"和"默认"标签存在
3. 管理员登录后台，在分组管理区域添加"测试分组"，确认 groups.json 更新
4. 上传新作品，选择"测试分组"，确认作品归入该分组
5. 回到作品广场，点击"测试分组"标签，确认只显示该分组作品
6. 编辑作品，修改分组为"默认"，确认分组变更生效
7. 在管理后台删除"测试分组"，确认该分组下作品自动归入"默认"
8. 确认现有作品（毛豆上货）自动获得"默认"分组
